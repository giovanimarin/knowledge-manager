# KnowledgeManager

Plataforma própria de gestão de conhecimento corporativo: documentos colaborativos, RAG, chat omnichannel e identidade federada.

Fase atual: PKG-00 — auditoria técnica e especificação. Docmost, AnythingLLM, Keycloak e Unified Channel são referências de engenharia, não aplicações integradas. Segurança multi-tenant, autorização antes da recuperação, testes automatizados e validação de licenças são obrigatórios. Nenhum serviço pago sem aprovação.
