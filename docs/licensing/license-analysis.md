Escopo da inspeção: arquivos rastreados de licença/aviso, manifestos e fontes citadas. A análise de dependências transitivas, imagens, modelos, pesos, dados, marcas e arquivos com cabeçalho próprio fica para seleção de versões. No PKG-01, gerar SBOM a partir dos locks e imagens, bloquear licença desconhecida ou incompatível e manter aprovação por dependência. Este PR contém documentação produzida para o projeto. Nenhum código de referência foi incorporado.
